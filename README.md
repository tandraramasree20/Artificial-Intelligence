# AI Smart Course Portal — U24CD501

Responsive static course website built from the supplied Artificial Intelligence syllabus for B.E. CSE, academic year 2026–27.

## Files
- `index.html` — page structure and course sections
- `styles.css` — responsive visual design
- `script.js` — syllabus search, outcome cards, 15-week plan, quiz and reflection note

## Run locally
Open `index.html` in a recent browser. No build step or backend is required. The page uses a Google Fonts CSS import as an optional enhancement; system fallbacks remain available offline.

## Publish with GitHub Pages
1. Sign in at https://github.com and create a public repository named `ai-smart-course-design-u24cd501`.
2. Upload the contents of this folder directly to the repository root, so `index.html` is at the root.
3. Select **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for the Pages deployment workflow to succeed. Test the actual URL shown by GitHub; it normally resembles `https://YOUR-USERNAME.github.io/ai-smart-course-design-u24cd501/`.

## Academic note
Course details and CO statements follow the supplied syllabus. The 15-week schedule is illustrative, because no official academic calendar or unit-wise weightages were present in the source. The site is a study aid, not a student-record, grading or authentication system. Do not publish personal student data here.
